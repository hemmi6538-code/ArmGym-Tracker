# 🏋️‍♂️ ArmGym Tracker

**ArmGym Tracker** — это автономное интерактивное веб-приложение (PWA) для профессиональных армрестлеров и любителей, разработанное для отслеживания тренировочного прогресса, симуляции поединков и грамотного подвода к весовой категории.

## 🗂️ Основной функционал

*   **Дневник тренировок:** Быстрая запись рабочих подходов с выбором руки, стиля борьбы (Верх, Крюк, Клюшка, Кингсмув, Трицепс) и конкретного специализированного вектора.
*   **Двухраундовый симулятор поединка:** Продвинутый движок симуляции матча. При равных силах соперников активируется **механика срыва захвата** и поединок переходит в раунд борьбы в ремнях (завязках).
*   **Интерактивный план сгонки веса:** Пошаговый 14-дневный чек-лист по водно-солевой загрузке и углеводной яме перед соревнованиями с сохранением прогресса.
*   **Календарь соревнований:** Актуальное расписание ключевых турниров на 2026 год с автоматическим отслеживанием статуса матчей.
*   **Секундомер статики:** Высокоточный таймер для контроля времени удержания критических рабочих углов.

## 🔋 Особенности приложения

1.  **Полная офлайн-автономия (PWA):** Благодаря встроенному Service Worker приложение кэшируется на ваше устройство и работает в лесу на тренировках вообще без доступа к интернету.
2.  **Сохранение прогресса:** Все данные тренировок и чек-листа сгонки веса сохраняются локально в вашем браузере (`localStorage`).
3.  **Адаптивный дизайн:** Интерфейс полностью оптимизирован под мобильные телефоны и ПК.
